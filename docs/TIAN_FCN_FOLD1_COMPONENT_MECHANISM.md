# Tian FCN Fold 1 PIR/MDP 机制诊断

日期：2026-07-29

## 结论

point-GT 救援后的定位长尾不是 FFT 符号、速度标签或环形边界造成的，主要是两阶段
后处理失败：

| 责任单元状态 | 样本数 | 占 53 个目标的比例 | 解码欧氏误差均值 |
|---|---:|---:|---:|
| 所在连通域被淘汰 | 17 | 32.08% | 53.81 |
| 位于胜出域，但 MDP 选了其他单元 | 28 | 52.83% | 3.80 |
| 被 MDP 选中 | 8 | 15.09% | 1.58 |

53/53 个目标的 PIR 均产生 2 个连通域，胜出域均为沿多普勒方向的 `12x1` 条带。
责任单元有 36/53 位于胜出域，但只有 8/53 最终被最小偏移规则选中。这说明此前的
`mdp_detection_count=1` 只是“最终输出一个检测”，不能解释为“PIR 只有一个连通域”。

## 原始 H 通道核对

- 53/53 个样本均与既有 H/V 原始峰值审计逐一匹配；
- H 局部速度峰 51/53 精确位于标签 bin，53/53 位于标签的正负 1 bin；
- 责任单元被选中的 8 个样本，`H_label_db` 均值为 27.35 dB；
- 位于胜出域但被 MDP 选偏的 28 个样本均值为 22.22 dB；
- 所在连通域被淘汰的 17 个样本均值为 20.66 dB。

原始强度与失败机制存在关联，但 `source_file` 基本绑定单一速度，因此当前数据不能
把采集源、速度和信号强度的影响作因果分离。

## 代码机制

point-GT 每张目标图只有一个分类正单元。原目标函数按“正负样本数相等”随机采样，
所以每张目标图只采一个分类负单元，其余绝大多数输出单元不受分类损失约束。这与
验证中稳定出现的宽多普勒条带相符。

跨样本概率图审计进一步确认这是固定模板：53 张目标图与平均概率模板的相关系数均值
为 0.99818。两个域不接触 Doppler 边界，而是稳定落在 `y=2-13` 和 `y=18-29`，
对应当前目标数据正、负径向速度的大致支持带。网络主要学到了“目标通常在哪些速度
区间和距离列出现”，没有形成逐样本的速度定位响应。

## 负样本下限消融

预登记消融只把目标图随机负样本下限从 0 改为 16，其余条件不变。完整 GPU 重跑得到：

| 指标 | 原 point-GT | 负样本下限 16 |
|---|---:|---:|
| validation joint Pd | 0.4151 | 0.2453 |
| validation Pfa | 0.0133 | 0.0067 |
| 速度 MAE / bin | 18.57 | 24.92 |
| 责任单元位于胜出域 | 36/53 | 27/53 |
| 责任单元被 MDP 选中 | 8/53 | 9/53 |
| 胜出域平均大小 | 12.00 | 12.47 |
| 概率模板相关系数均值 | 0.99818 | 0.99850 |

该消融降低了分类损失和背景虚警，但没有缩小模板条带，且主定位指标明显退化，正式
判为 `REJECT`。不得继续扫描随机负样本数或 PIR 阈值。

## 同距离列密集负监督消融

第二项预登记消融把责任单元所在距离列的其余 31 个速度单元全部作为负样本，其他
条件仍保持不变。结果同样不通过：

| 指标 | 原 point-GT | 同距离列密集负监督 |
|---|---:|---:|
| validation joint Pd | 0.4151 | 0.1132 |
| validation Pfa | 0.0133 | 0.0133 |
| 速度 MAE / bin | 18.57 | 32.30 |
| 责任单元位于胜出域 | 36/53 | 21/53 |
| 责任单元被 MDP 选中 | 8/53 | 5/53 |
| 胜出域平均大小 | 12.00 | 12.08 |
| 概率模板相关系数均值 | 0.99818 | 0.99817 |

密集负监督把目标概率均值压到约 0.025、验证阈值压到 0.0214，却没有增加逐样本变化，
说明它同时压制了弱目标响应和速度模板。该候选判为 `REJECT`。

当前 point-GT 分类监督分支到此停止，不再继续修改 BCE 采样、PIR 或 MDP。下一阶段
转为复现条件与数据可辨识性核对：确认论文/学长数据的输入轴、归一化、训练样本速度
与距离覆盖、同条件背景控制及原始超参数；在这些证据补齐前禁止新六折、V、HV 和
test，也不再启动新的 FCN 训练。
