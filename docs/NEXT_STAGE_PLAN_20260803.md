## 1. 采用外部建议后的判断

采纳的主线是：数据可信性 -> 虚警机制 -> 极化特征 -> 最小模型增量 -> 分组与外层验证。
当前不缺一个更大的网络，缺的是 H/V 和坐标事实、误警物理证据、同条件数据以及未消费的
外层评价。

附件中的建议与当前仓库相比，需要做三项校正：

1. 当前成果表、56 项多域特征目录和初步极化压力检查已经完成，不重复建立同类结果；
2. 历史 186/187 个误警可以先按可见结构审计，但建筑、鸟、地物等物理类别必须有独立
   场景记录，不能从文件名或 RD 图猜测；
3. `Polarization-aware BC-DPG-FCN` 是数据门通过后的候选，不在目标/背景日期完全混杂的
   六折上继续训练或选结构。

当前论文问题保持为：在 H/V 双通道 UAV/背景数据上，建立可追溯的检测、距离-速度定位和
复杂背景虚警抑制前端。空飘球载荷识别是新数据到位后的下一研究对象。

### 3.2 极化小模型所需的最小新数据

这批数据用于回答“极化信息是否在同条件下帮助区分目标和背景”，必须具备：

- 同一日期、场地、雷达配置和标定状态下同时采目标与无目标背景；
- H/V 成对数据；优先原始复数 IQ，至少保留未分别自适应归一化的线性功率；
- `session_id`、`scan_id`、硬件时间戳/序号、目标存在、距离、径向速度和背景类型；
- 每个通道的有效标志、标定编号、异常/丢帧记录；
- 多个独立 session，按 session 或日期分开发、验证和 locked test，不能切片后随机混分；
- 背景物理类别若要命名，必须有现场记录、视频或日志，允许大量样本标 `unknown`。

先做小规模 pilot 检查格式、同步、类间同条件对照和特征稳定性；pilot 通过后再扩数量。当前
不预先承诺一个样本条数，因为独立 session 数、场景覆盖和外层隔离比从同一记录切出更多帧
更重要。

### 3.3 时域、因果 BC 和微多普勒额外需要的数据

- 连续逐脉冲慢时间复数 IQ，而不是互不连续的单帧 RD 图片；
- 真实 PRF、脉冲序号、帧序号、UTC 时间戳、时钟重置和丢帧日志；
- 每个事件的开始/结束、连续时长及雷达配置；
- 雷达与视频/运动真值的同步关系和误差；
- 固定正式配置下至少 300 秒连续写盘能力测试，用于验证吞吐和连续性；
- 多个独立连续事件，开发、验证和锁定测试按 session 隔离。

这些材料到位后，才能计算有物理时间/频率单位的 STFT、时频脊线、周期和微多普勒特征；
现有 128 脉冲单帧只允许结构描述，不能支持物理微多普勒结论。

### 3.4 空飘球载荷与状态识别额外需要的数据

- `balloon_unloaded`、`balloon_loaded`，以及明确的 `payload_class`；
- 稳定、摆动、旋转等 `motion_state`，并由同步视频或传感器记录确认；
- 多个球体、多个载荷实例、多个日期/场地和重复独立放飞 session；
- 同条件 UAV、鸟类、其他目标和无目标背景，支持检测前端的混淆分析；
- 距离、径向速度、方位、SNR、天气和风况；
- 类别与 session 不得一一绑定，locked test 中需要未见过的 session/日期或实体。

建模顺序应是：目标/背景检测 -> 空飘球/其他目标 -> 有载/无载 -> 载荷或运动状态细分，
不直接用当前 UAV 六折训练一个“空飘球识别器”。

## 4. 极化特征的使用边界

| 候选量 | 可用条件 | 当前命名 |
|---|---|---|
| `|H|^2 + |V|^2` | H/V 均有效，线性量纲一致 | 双通道总功率 |
| `P_H / (P_V + eps)` 或 dB 比 | 幅度响应至少可比较；未绝对标定 | relative H/V ratio、ZDR-like |
| `P_H / (P_H + P_V + eps)` | H/V 同步且尺度可比 | 相对归一化功率 |
| `|H - V|`、复相关、相位差 | H/V 同步、相干、相位对齐且处理链明确 | 门通过后再定义 |
| 极化一致性 loss | 有可信监督或预登记的自监督物理约束 | 当前不启用 |

因此第一版候选不是直接上极化注意力，而是先验证总功率、相对功率比和 ROI 统计。简单分支
在新验证组稳定后，才比较 gated fusion/attention；物理约束 loss 必须最后考虑。

## 5. 交付与停止规则

1. 新数据先填 `configs/data_collection_manifest_template_v1.csv`，再运行
   `validate_data_collection_manifest.py`；原始大文件不进 Git 或分享包。
2. 特征定义、归一化拟合范围、阈值、主指标和停止规则在读取 locked test 前冻结。
3. 主指标至少包含 Pfa、joint Pd、最差背景组、定位误差和配对新增/移除误警；AUC 只作补充。
4. 如果特征主要编码日期、文件来源或扫描组，停止模型化并保留负结果。
5. 如果困难验证组未通过，停止六折扩展；不靠更多 epoch、更多通道或 test 调参挽救。
6. complete-scan BC 始终标为离线扫描感知上限；只有真实 past-only 顺序可称因果方案。
