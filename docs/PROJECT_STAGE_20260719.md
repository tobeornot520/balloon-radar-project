# 雷达项目阶段状态与后续目标（2026-07-19）

## 当前阶段

当前工作属于 **Background + UAV 完整检测与距离—速度定位前端**，不是最终空飘球载荷分类。
旧的 318 个仅 UAV 正样本定位实验已经冻结，只作历史基线。

## 样本级诊断结论

- HV 相对 H 救回 6 个正样本、退化 3 个，净增加 3 个正确样本。
- HV 分数检出 51/53，但联合正确 44/53；主要瓶颈是 7 个定位失败。
- HV 的 7 个定位失败距离误差均为 3 门，速度误差均不超过 1 单元。
- 其中 6/7 的预测距离比标签近 3 门，存在向近距离方向的系统偏差迹象。
- 5 个发生虚警的背景样本全部来自扫描时刻 `20260204_100739`，需优先检查该扫描的固定杂波、近零多普勒响应和数据质量。
- H/V 的互补信息尚未被简单早期拼接稳定利用。

## 实验纪律

1. 不得依据测试集重新选择阈值、距离容差或固定偏移。
2. 所有校准、后处理和模型选择只能由训练集/验证集确定。
3. 新模型必须保持相同数据划分、随机种子、训练轮次、阈值策略和评价判据。
4. 测试集已被逐样本检查，最终论文需采用分组交叉验证或新采集锁定测试集确认。
5. 当前 UAV 检测结果不得直接表述为空飘球载荷识别结果。

## 固定推进顺序

1. 关键样本可视化：H/V/HV 输入、模型热图、标签点和预测点。
2. 仅在验证集分析有符号距离误差，并锁定候选距离校准。
3. 若验证集确认偏差稳定，再将验证集锁定规则一次性应用到测试集。
4. 建立 H/V 独立编码的晚期融合基线。
5. 建立 RI4：`Re(H), Im(H), Re(V), Im(V)`。
6. 建立 Polar6：RI4 + `sZdr` + `sρco`，极化量必须由原始复数 H/V 在独立归一化前计算。
7. 完成上述公平基线后，才考虑极化门控、注意力和更复杂多域融合。

## 长期目标

检测定位前端 → 目标类别 → 空飘球有载/无载 → 载荷类型 → 静稳/摆动/旋转状态。
后续需要补齐空飘球、带载空飘球、鸟类等真实数据和长慢时间时频/微多普勒数据。
