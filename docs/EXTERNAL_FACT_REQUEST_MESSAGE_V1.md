# 外部事实确认可转发消息 V1

版本：2026-08-02  
用途：推进 D01、D02、D10。下面两段可直接复制发送；长问题清单与填写模板保留在文末所列附件中。

## 给学长：Tian 复现与数据条件

```text
学长您好，我正在用现有 H/V 雷达数据做 Tian 2024 的复现准备。当前本地迁移出现固定多普勒模板，且目标都集中到同一输出距离列；我想先把条件对齐，不再盲目调参。

如果方便，能否优先确认以下五点中的任意几项：
1. 推荐复现用论文原始数据、同分布数据还是当前这套本地数据？对应 train/val/test 划分是什么？
2. 能否给一个最小对齐样例：输入文件、进入网络前张量、标签/GT、网络输出，或一个 checkpoint/配置？
3. 输入到底是 IQ、线性功率 RD、dB RD 还是归一化图？两个轴、FFT/fftshift、零多普勒和正负号如何定义？
4. 5x7 GT、标签坐标和输出网格的轴顺序/0-1 base 如何对应？
5. 分类负样本、PIR/MDP 和模型选择的关键规则是什么？

文字、截图、配置片段或一个可授权样例都可以。我们会将答复只用于受控复现记录，不会公开原始数据、权重或个人路径。谢谢！
```

## 给设备或数据负责人：H/V、时间与坐标事实

```text
您好，我们正在确认现有 H/V 雷达数据是否能支撑后续极化、时域和空飘球研究。为了避免根据旧文件猜测，想请协助确认以下事实；不知道的项目可以直接标“待实测”。

1. H/V 分别代表什么？是同时采样、交替采样还是切换采样？能否导出原始复数 IQ？
2. PRF、每帧脉冲数、距离门数、距离分辨率、窗函数/FFT/fftshift、零多普勒位置和速度正负号分别是什么？
3. 距离与速度标签到 bin 的公式、索引起点和一帧/波束/扫描/文件的关系是什么？
4. 是否有真实硬件时间戳、单调序号和时钟重置/丢帧记录？文件名和 mtime 不足以替代这些信息。
5. H/V 幅相标定、相干关系、导出前积累/检测/降采样/校正，以及一个最小原始样例和对应配置是否可提供？

配置导出、说明书页、截图或脱敏样例都可以。原始大文件和设备序列号会保存在受控目录，不进入公开分享包。谢谢！
```

## 收到答复后的固定动作

1. 保存原消息、附件和答复时间到受控本地目录，不提交聊天记录或原始文件；
2. Tian 答复填入 `configs/tian_fcn_reproduction_conditions_evidence_v1.csv`；
3. 设备答复填入 `configs/field_capability_response_template_v1.csv`；
4. 把可引用事实与仍不确定项更新到 `docs/DATA_CARD.md`；
5. 通知我后，我会核对来源、更新任务台账和重新运行当前方向完成判定。
