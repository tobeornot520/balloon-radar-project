# Tian 2024 复现受阻说明、失败分析与替代路线

版本：2026-08-03

适用对象：项目组、指导教师、提供论文与数据的学长

当前决策：精确复现冻结；保留方法级实现和负结果；立即转入可执行替代路线

## 1. 一页结论

当前不能把 Tian 等 2024 年论文称为“复现成功”，也不能把现有负结果简单解释为论文
算法无效。项目现在面对的是三个不同层次的问题：

1. **精确或数值级复现不可验证。** 原数据、原代码、checkpoint、完整预处理、标签几何、
   训练配置和一个输入-标签-输出对齐样例均不可获得。论文文字存在轴顺序、损失权重和
   PIR/MDP 实现细节歧义，无法证明本地实现与原实现完全一致。
2. **原 Tian 结构在当前本地数据上的迁移失败。** 修正指标和后处理后，模型仍学习成
   近似固定的多普勒概率模板，不能形成可靠的逐样本定位响应。两项预登记监督消融均未
   修复该问题。
3. **论文思路的本地改造也没有通过泛化检验。** 六通道 H/V thesis adapter 在单个验证
   背景扫描组上表现较好，但在另一个已冻结背景扫描组上出现 134/150 个虚警，说明模型
   学到的背景分布不能跨扫描组稳定迁移。

因此，当前最严谨的表述是：

> 已完成 Tian FCN 的方法级独立实现、本地迁移和失败机制诊断；由于复现条件不可获得、
> 本地标签覆盖不足以及背景扫描组分布偏移，目前无法完成论文数值级复现。原 Tian 迁移
> 与本地改造均未达到可接受的泛化标准，后续不再无约束扫参。

这是一项可报告的**负结果和条件诊断**，不是“什么都没做出来”，但也不是论文复现成功。

### 2.2 Tian 精确复现条件

当前缺少：

- 论文数据的版本、样本清单与固定 train/validation/test 划分；
- 原始 IQ 到网络输入的完整预处理、轴顺序、归一化和 padding 规则；
- `5 x 7` GT 的轴顺序、索引基准、分类正区域和回归责任单元定义；
- 负样本采样、三阶段训练、损失权重、优化器和模型选择细节；
- PIR 阈值、连通域邻接、候选域选择与 MDP 域内定位的可执行规则；
- 原代码、checkpoint、训练日志或至少一个可逐层核对的输入-标签-输出样例；
- 学长期望达到的指标、容差和同分布数据说明。

论文正文可以约束方法的大框架，但不能唯一确定上述工程实现。继续猜测其中任一项，可能
通过调参得到更好数字，却无法证明数字来自正确复现。

## 3. 已经完成了什么

项目并非停留在“网络尚未搭建”。已经独立实现并测试：

- Tian 风格 FCN 的分类头和距离/多普勒偏移回归头；
- 扩展 GT、point-GT 和回归责任单元构造；
- PIR 动态阈值、连通域筛选和 MDP 定位；
- validation-only 阈值选择、单折训练器和六折编排器；
- 论文距离指标、`d_min`、`d_5`、`d_avg` 的修正口径；
- 概率模板、连通域、责任单元、数据覆盖和负监督机制审计；
- 独立的六通道 H/V thesis adapter 与直接最大值解码。

也就是说，当前失败不是“程序报错”或“尚未实现”，而是**实现可以运行，但结果没有
通过预登记的定位、非退化和跨背景组泛化门槛**。

## 4. 原 Tian 本地迁移的失败证据

### 4.1 第一轮结果不能作为成功复现

第一轮 H-only 六折迁移得到零联合检测。其后审计还发现该版本使用了非论文 L1 距离，
并错误实现了 `d_min/d_5/d_avg`。因此该轮只保留为历史失败记录，不报告为有效论文指标。

### 4.2 修正后扩展 GT 仍无法完成定位

修正实现后，Fold 1 扩展 GT 的 validation joint Pd 仍为 0。问题不只是阈值偏高：目标
责任单元虽能进入 PIR 候选，但 MDP 最终选择了其他网格单元。

### 4.3 point-GT 只完成了部分救援

只改变分类标签为 point-GT、保持其他设置冻结且不加载 test 后，Fold 1 validation 得到：

| 指标 | 结果 |
|---|---:|
| 目标 / 背景 | 53 / 150 |
| 正确检测并定位 | 22/53 |
| joint Pd | 0.4151 |
| 背景虚警 | 2/150 |
| Pfa | 0.0133 |
| 责任单元被 MDP 选中 | 8/53 = 0.1509 |
| 速度 MAE | 18.57 bins |

point-GT 说明“扩展分类区域与单点回归责任单元失配”确实是失败原因之一，但 22/53 和
8/53 不能构成成功定位复现。

### 4.4 网络学习的是公共模板，不是逐样本响应

53/53 个验证目标都产生两个约 `12 x 1` 的多普勒条带。各目标概率图与公共平均模板的
相关系数均值为 `0.99818`。这表明输出几乎不随输入样本改变，网络主要记住了目标在训练
数据中常出现的速度支持带。

两项预登记消融没有解决模板退化：

| 设置 | joint Pd | Pfa | 速度 MAE / bin | 模板相关系数 |
|---|---:|---:|---:|---:|
| point-GT | 0.4151 | 0.0133 | 18.57 | 0.99818 |
| 每图至少 16 个随机负样本 | 0.2453 | 0.0067 | 24.92 | 0.99850 |
| 同距离列密集负监督 | 0.1132 | 0.0133 | 32.30 | 0.99817 |

增加负监督只是压低了目标分数，没有增加样本依赖性，两项候选均已判为 `REJECT`。

## 5. 为什么当前本地数据难以辨识 Tian 模型

### 5.1 距离维覆盖塌缩

Fold 1 清单中的 318 个目标映射到 Tian 输出网格后全部位于 `grid_x=4`。模型几乎没有
机会学习“输入变化如何对应不同输出距离列”，最容易的解是始终预测同一列。

### 5.2 速度、采集源和信号强度纠缠

71 个目标采集源中有 47 个只对应一个速度值。目标速度、源文件和信号强度彼此关联，
模型可能利用采集来源特征预测速度模板，而不是学习可迁移的目标定位机制。

原始 H 通道局部速度峰其实与标签较一致：Fold 1 validation 中 51/53 精确落在标签 bin，
53/53 位于正负 1 bin。这说明原始输入包含速度线索，但当前监督、网格和数据覆盖没有让
FCN 稳定利用该线索。

### 5.3 目标与背景采集条件不匹配

当前六折中，318 个目标全部来自 `20260202`，830 个背景全部来自 `20260204`。类别与日期
完全耦合。模型可能学习日期、硬件状态、背景功率或处理流程差异，无法证明只学习了目标
结构。

## 6. thesis 风格本地改造为什么仍被拒绝

六通道 H/V thesis adapter 使用 `2 x 2` pooling、`32 x 25` 输出网格和直接最大值解码，
成功消除了原 Tian 迁移的固定模板退化。在 Fold 1 validation 上，稳定的逐样本归一化版本
得到：

- joint Pd：`50/53 = 0.9434`；
- Pfa：`1/150 = 0.0067`；
- 模板相关系数：`0.3557`。

但冻结模型和阈值后，只进行一次本地 held-out 评价，结果变为：

- joint Pd：`30/53 = 0.5660`；
- Pfa：`134/150 = 0.8933`。

validation 背景全部来自扫描组 `20260204_100802`，其中 145/150 个峰位于 Doppler 输出
边缘；held-out 背景全部来自 `20260204_100739`，其中 125/150 个峰位于零多普勒行。
这不是轻微阈值误差，而是明显的背景扫描组机制变化。用 held-out 分数重调阈值会形成
测试集调参，因此该候选被拒绝为泛化检测器。

## 7. 根因判断：哪些已证实，哪些仍不能区分

| 原因 | 判断 | 证据边界 |
|---|---|---|
| 旧指标和后处理实现存在错误 | 已证实并修正 | 只能解释第一轮指标无效，不能解释修正后的全部失败 |
| 扩展 GT 与单点回归责任不一致 | 已证实为部分原因 | point-GT 有改善，但仍未解决定位 |
| 当前目标距离覆盖不足 | 已证实 | 318/318 位于同一输出距离列 |
| 当前监督产生固定速度模板 | 已证实 | 模板相关约 0.998，两个负监督消融均失败 |
| 背景扫描组发生明显分布偏移 | 已证实 | thesis adapter 的 held-out Pfa 为 134/150 |
| 本地实现与论文原实现完全一致 | 无法验证 | 缺原代码、配置或对齐样例 |
| Tian 原算法在原论文数据上无效 | 不支持该结论 | 当前不是同数据、同处理链的数值复现 |
| 零频响应对应某一种具体物理杂波 | 无法判断 | 缺 IQ 处理链、PRF、场景记录和设备证据 |

因此失败应写成“本地迁移与本地改造未通过”，不能写成“推翻 Tian 论文”。

## 8. 为什么不继续盲目跑网络

1. 学习率、PIR 阈值或负样本数不能补齐轴顺序、标签几何和输入量纲的未知信息。
2. 在已消费的 validation/held-out 结果上继续选结构，会逐步把测试信息用于开发。
3. 当前数据的距离列和速度覆盖不足，更多 epoch 更可能强化固定模板。
4. 在 H/V 定义与相干性未知时直接扩展 V/HV，可能把设备差异误写成极化收益。
5. 即使偶然得到更好数字，也无法判断来自正确复现、数据泄漏还是扫描组过拟合。

停止无约束扫参是为了保留证据可信度，不是放弃后续研究。

## 9. 可立即执行的替代方案

### 方案 A：主线改为当前 DPG-FCN 检测与虚警机制研究

这是当前最优先、与已有数据最匹配的路线：

- H/V 双支路 DPG-FCN 继续作为检测和距离-速度 bin 定位前端；
- 固定 Gaussian soft notch 作为确定性零多普勒抑制参考；
- 受约束 residual V2 只允许在零频附近进一步降分；
- 继续完成人工虚警复核和跨背景组压力分析；
- 所有结果标为当前 6 个背景扫描组上的内部开发证据。

当前同口径结果为：CPU 基线 187 个虚警、固定 notch 120 个、固定 notch 加 residual V2
109 个；联合命中分别为 289/318、290/318、290/318。该路线能形成完整的大创中期成果，
但不能替代 Tian 数值复现或外部盲测。

### 方案 B：把 Tian 分支降级为“方法实现与失败机制案例”

保留现有 Tian 模型、目标函数、PIR/MDP 和测试，不再进行性能扫参。后续只允许：

- 单元测试与合成小样例验证坐标、GT、PIR 和 MDP 的代码合同；
- 对已存在结果做可重复的机制审计；
- 在报告中比较“原结构为何退化”和“thesis adapter 为何跨组失败”；
- 一旦获得原始对齐样例，再从一个样本开始重开，而不是直接跑六折。

这条路线的成果名称应为“方法级实现与本地适用性诊断”，不能写“论文指标复现”。

### 方案 C：使用 LAT-MRICD-1.0 建立独立公开数据基线

已下载的公开数据含 7,119 条 X/Ku HRRP 和 16,072 条 S/X/Ku 窄带 I/Q，可用于：

- UAV / 鸟类 / 气象目标三大类识别；
- 归一化包络、相位增量、自相关、归一化谱、谱熵和谱展宽基线；
- Narrow-X 与 HRRP-X 的 batch-grouped 线性/树模型；
- 基线稳定后再比较一维 CNN 和跨频段迁移。

必须按 `(representation, band_code, batch_code)` 分组，禁止随机拆行。没有可验证 PRF 时，
频率只写 cycles/sample 或 normalized frequency。该数据不含 H/V、空飘球标签和 Tian 对齐
事实，因此是独立算法预研，不是假装补齐原复现。

### 方案 D：当前 H/V 数据统一采用降级表述

在设备事实不可获得期间：

| 原计划 | 当前替代 | 不允许的表述 |
|---|---|---|
| 物理速度与微多普勒 Hz | Doppler bin、归一化频率和图形结构 | 真实 Hz、m/s 或物理周期 |
| 绝对极化特征 | relative H/V power、ZDR-like、通道分支消融 | 绝对 ZDR、PhiDP 或散射机理 |
| 相干相位融合 | 默认关闭相位差与复相关分支 | 声称 H/V 相干或已标定 |
| 因果时序模型 | 样本独立模型；完整扫描仅作离线上限 | 把推定顺序称为实时 past-only |
| 物理虚警类别 | 可见结构加 `physical_class=unknown` | 从 RD 图猜建筑、鸟或地物 |

该降级方案允许继续做工程研究，但不会制造不存在的物理事实。

### 方案 E：未来重新采集一个最小可验证 Pilot

如果以后可以接触雷达但仍拿不到旧资料，优先新采而不是继续追旧参数。最小 Pilot 需要：

- 同配置、同日期、同场地的目标和无目标背景；
- H/V 原始复数 IQ，以及通道同时/交替采样说明；
- PRF、脉冲数、距离门、窗函数、FFT/fftshift 和坐标公式；
- UTC 时间戳或硬件序号、丢帧记录、session/scan/event ID；
- H/V 通道检查与 calibration ID；
- 多个独立 session，并预留不参与选择的 locked test。

新 Pilot 先通过 `capture`、`causal` 和 `locked_evaluation` 合同，再启动极化、微多普勒或
Tian 风格模型训练。

## 11. Tian 分支重新开启的唯一条件

满足以下任一项，才允许建立新预登记：

1. 原代码或 checkpoint，加一个输入、标签和输出可对齐样例；
2. 完整预处理、轴顺序、标签构造、后处理和训练超参数；
3. 一套覆盖多个输出距离列和速度行、具有同条件背景的同分布数据。

重开后也只先做：一个样本逐层核对 -> 一个小 train/validation split -> 非退化检查。
三步均通过后才考虑六折。任何旧 held-out 结果都视为已消费，不再作为盲测。
