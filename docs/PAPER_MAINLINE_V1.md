# 当前论文主线与写作边界 V1

版本：2026-08-02  
适用范围：现有 H/V 双极化 UAV/背景数据上的检测、距离-速度定位和复杂背景虚警抑制。  
不适用范围：空飘球载荷识别、跨场地盲测、严格实时部署和物理微多普勒定量。

## 1. 论文要回答的问题

> 在当前 H/V 双极化雷达数据条件下，如何建立可追溯的低慢小 UAV 检测与距离-速度定位
> 前端，并识别复杂背景虚警的机制、收益和部署边界？

论文不是“已经完成空飘球载荷分类”，也不是“某一个更大网络取得更高 AUC”。核心贡献是把
候选检测、背景校准、定位口径、零多普勒虚警、极化限制和数据门禁放在同一条可审计链路中。

## 2. 可用题目与摘要定位

推荐题目：

> 面向低慢小目标雷达检测定位的 H/V 双通道候选校准与复杂背景虚警审计

摘要中的对象必须写为“UAV 与背景数据上的检测定位前端”。空飘球有载/无载、载荷类型、
摆动或旋转状态只作为后续可迁移方向，不能出现在结果性结论中。

## 4. 当前主表和必要图件

主表必须以统一的 `joint Pd` 与 `Pfa` 口径报告，并至少包含 pooled、macro 或折分布、最差折
和定位误差摘要。当前内部开发参考如下：

| 方案 | 背景误警 | 联合成功 | 正确角色 |
|---|---:|---:|---|
| 完整扫描上下文 BC-DPG v3 | 56/830 | 289/318 | 离线扫描感知上限，不是严格实时方案 |
| 样本独立 BC | 122/830 | 289/318 | 更接近在线条件的独立训练对照 |
| 固定 soft notch | 120/830 | 290/318 | 零多普勒开发安全参考 |
| fixed notch + target-protected residual V2 | 109/830 | 290/318 | 六折开发比较参考，不是盲测或部署指标 |
| ROI RI4 | 196/830 | 268/318 | 局部极化抑制研究，不替代 BC-DPG |

必要图表：

1. 系统流程图：H/V IQ -> RD 候选 -> 背景校准/ROI -> 分数与定位输出；
2. 六折 pooled、macro、最差折与扫描组不确定性表；
3. 距离/速度误差 CDF 或分位数表，且报告最大误差长尾；
4. complete-scan、leave-one-out、past-only 和 sample-independent 的证据角色图；
5. 零多普勒虚警机制与 fixed/residual 配对变化图；
6. 极化候选特征的最差背景组压力表，不只展示 pooled AUC；
7. 新数据采集与锁定评价门禁图。

| 可以写 | 不可以写 |

## 6. 当前论文结论模板

本文在 H/V 双通道 UAV/背景雷达数据上建立了候选检测、联合距离-速度定位和背景虚警
审计流程。冻结内部开发证据表明，完整扫描上下文 BC-DPG 在该条件下具有较低的背景误警，
但其上下文可能包含后续样本，因此只能视为离线扫描感知上限；样本独立 BC 保留为更接近
在线条件的参照。零多普勒背景结构是当前虚警的主要可解释机制，固定抑制与目标保护残差
提供开发期收益，但仍需新的独立数据验证。相对极化特征和候选 ROI 接口具备后续价值，
但标定、时间同步、连续慢时间和同条件空飘球数据仍是载荷与状态识别的必要前提。
