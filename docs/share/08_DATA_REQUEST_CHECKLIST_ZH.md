# 后续数据需求与最小交付清单

本清单用于向学长、设备负责人或数据持有方说明“还需要什么”。它不要求对方直接发送
敏感或大型原始数据；第一步可以只提供字段说明、尺寸、配置和一个脱敏样例。

## 1. Tian 论文复现最小包

| 内容 | 最小要求 | 用途 |
|---|---|---|
| 样例输入 | 1 个原始或论文入口文件 | 核对变量、轴、数据类型和量纲 |
| 预处理张量 | 同一样例进入网络前的数组及尺寸 | 逐层对齐 FFT、归一化和 padding |
| 标签 | 原坐标、输出网格坐标和 GT 图 | 核对 0/1-based、轴顺序和责任单元 |
| 模型输出 | 分类图、回归图、PIR/MDP 最终检测 | 区分网络与后处理差异 |
| 配置 | epoch、batch、优化器、学习率、loss 权重 | 避免继续猜测训练条件 |
| 划分 | 固定 train/val/test 文件或组清单 | 防止样本泄漏和测试选型 |
| 参考结果 | 该版本预期 Pd/Pf 和距离指标 | 定义“复现成功”门槛 |

若可以提供完整数据，额外需要每个目标覆盖的距离、速度、SNR 和采集场景分布，以及
同条件纯背景。文件传输前应先确认使用权限和可分享范围。

## 2. 时域特征所需数据

- 连续复数 IQ，而不是只保存 RD 图片或单帧功率；
- pulse/frame/beam/scan 硬件序号及重置标志；
- PRF、脉宽、积累脉冲数、采样率、带宽和窗函数；
- 每个样本真实开始/结束 UTC 时间与丢帧记录；
- 目标状态开始、结束和不确定区间；
- 同条件背景段和可确认运动目标段；
- 原始缩放、量化、AGC 和导出前处理说明。

有了这些信息才能可靠计算幅度统计、相关性、相干时间、闪烁、周期性和状态转移特征。

## 3. 极化特征所需数据

- H/V 是否同时采样、交替采样或经过非相干处理；
- 通道物理定义、线缆和软件映射；
- 相对幅度、相对相位标定方法与 `calibration_id`；
- 固定参考目标和空场标定文件；
- 两通道饱和、缺失、噪声底和增益状态；
- 同一目标、同一时刻、同一雷达参数的 H/V 配对关系。

在相干与幅相标定通过前，只能使用 H/V 功率、相对 ZDR-like 和带 validity mask 的
工程特征，不能声称绝对 ZDR、散射矩阵或物理相位结论。

## 4. 微多普勒所需数据

- 足够长且连续的慢时间序列及真实 PRF；
- 未被跨帧打乱的脉冲顺序和明确的帧重叠关系；
- 目标距离门随时间的关联，避免直接在错误距离门提谱；
- 状态级时间标签：稳定、摆动、旋转、载荷晃动、起止过渡；
- 同一球体、载荷和距离下的重复 session；
- 视频或其他真值，用于确认周期、姿态和状态切换。

没有 PRF 时只能报告归一化频率；没有连续时序和状态区间时不能把单帧谱形命名为
物理微多普勒机制。

## 5. 空飘球与载荷分类所需场景

最小 Pilot 只做四类：纯背景、无载球、同一球体有载稳定、有载摆动/自然运动。每类
至少 3 个独立重启 session，每段 2-5 分钟，并保持同日期、同场地、同雷达配置和同
标定。正式数据再扩展：

- 多日期、多距离、多方位和不同风况；
- 轻载、中载、重载及不同悬挂长度；
- UAV、鸟类、气象和地物等干扰；
- 未参与任何开发的日期/场地作为锁定外层测试；
- 每个开发条件同时有纯背景和目标对照。

不能只让“目标类别=某一天、背景类别=另一天”，否则模型可能只学习日期和设备状态。

## 6. 每个 session 的最低元数据

| 类别 | 必须记录 |
|---|---|
| 身份 | `session_id`、日期、场地、重复编号、操作者 |
| 雷达 | 设备/固件、`radar_config_id`、PRF、带宽、脉冲数 |
| 时间 | UTC 起止、硬件序号、时钟源、重置与同步误差 |
| 通道 | H/V 有效性、相干方式、`calibration_id`、饱和率 |
| 目标 | 球体、载荷、悬挂、状态区间、距离/方位/高度真值 |
| 环境 | 风速风向、天气、遮挡、电磁异常 |
| 文件 | 相对路径、字节数、SHA256、备份状态和接受/拒绝原因 |

完整空白模板位于 `assets/templates/`，详细门禁见
[外场采集 SOP](../evidence/19_FIELD_COLLECTION_SOP.md)。

## 7. 数据接收后的第一轮检查

1. 只读保存原件并生成 SHA256；
2. 核对文件数、变量、尺寸、复数类型、NaN/Inf、饱和和序号连续性；
3. 核对 H/V 配对、UTC 映射、PRF 与配置版本；
4. 按 session 生成清单，不按单样本随机拆分；
5. 先保留锁定外层数据，再开展训练/验证；
6. 先运行小样例逐层对齐和 smoke，再决定是否正式训练。
