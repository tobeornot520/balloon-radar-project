# 当前成果与证据

## 1. 当前主结果：固定阈值六折联合审计

最终联合审计精确对齐六折 1,148 条测试记录，其中背景 830 条、目标 318 条。BC 判决来自冻结的 `base_threshold_test_predictions.csv`，ROI 判决来自冻结的 `refined_fixed_*` 列，测试阈值没有重新调整。

| 方法 | 虚警数 | Pfa | 正确检测 | pooled Pd |
|---|---:|---:|---:|---:|
| BC-DPG-FCN v3 | 56 | 0.0675 | 289/318 | 0.9088 |
| Power2 baseline | 300 | 0.3614 | 268/318 | 0.8428 |
| ROI power control | 237 | 0.2855 | 268/318 | 0.8428 |
| ROI RI4 | 196 | 0.2361 | 268/318 | 0.8428 |

当前决策是保留 BC-DPG-FCN v3 作为最强检测器。ROI RI4 相对其自身 Power2 候选基线减少 104 个虚警，并保持 268 个正确检测，说明局部极化抑制机制有效，但整体仍未超过 BC-DPG v3。

![六折检测权衡](../assets/figures/joint_pooled_detection_tradeoff.png)

## 2. BC-DPG 与 ROI RI4 的互补性

| 结果分区 | 数量 |
|---|---:|
| 共同虚警 | 36 |
| 仅 BC-DPG 虚警 | 20 |
| 仅 ROI RI4 虚警 | 160 |
| 虚警并集 | 216 |
| 共同正确目标 | 263 |
| 仅 BC-DPG 正确 | 26 |
| 仅 ROI RI4 正确 | 5 |
| 正确目标并集 | 294 |
| 两者均未正确 | 24 |

![互补性分区](../assets/figures/joint_complementarity.png)

逻辑 AND 可把虚警降至 36，但正确检测降至 263；逻辑 OR 可把正确检测提高到 294，但虚警升至 216。这些数字是测试集上的描述性诊断，不是已选择的组合规则。

## 3. BC-DPG v3 独立冻结证据

BC-DPG 最终报告还比较了原始 DPG、样本独立校准和完整扫描上下文校准：

| 方法 | 六折虚警 | 平均 Pd | 说明 |
|---|---:|---:|---|
| 原始 DPG-FCN | 186 | 0.9059 | 冻结检测定位前端 |
| 样本独立 BC | 122 | 0.9059 | 不使用扫描上下文 |
| 完整扫描上下文 BC-DPG v3 | 56 | 0.9059 | 当前冻结主模型 |

![BC-DPG 部署条件比较](../assets/figures/bc_dpg_deployment_false_alarms.png)

这里的 `平均 Pd` 是六折指标的算术平均；联合审计中的 `pooled Pd` 是合并 318 个目标后的计数比例，两者统计口径不同，不应直接混写。

## 4. 显式极化 Stage 3

Stage 3 只使用 Fold 1 和 Fold 4 两个困难折，用于方法诊断：

- Power2 的低 FPR 排序和联合检测率最高；
- RI4 的固定阈值虚警和验证—测试背景超阈比例最低，但检测率下降；
- Polar6-gated 与 RI8-gated 没有形成稳定独立增益；
- 因此不将密集极化表征扩展为六折主检测器。

两折结果不能与六折主结果当作同一证据等级比较。

## 5. ROI Stage 4

Stage 4 冻结 Power2 候选位置，只允许局部 ROI 调整候选分数。两折预注册后，仅将 Power2 baseline、ROI power control 和 ROI RI4 扩展到六折。

结果说明 ROI 机制可以减少自身候选链路的虚警，但验证—测试背景迁移仍明显，因此 ROI 不替代 BC-DPG 的背景条件校准。

## 6. 证据等级

| 证据 | 范围 | 可支持的结论 |
|---|---|---|
| H/V/HV 历史基线 | 早期固定划分 | 通道特性和定位问题诊断 |
| Stage 3 显式极化 | 两个困难折 | 表征筛选和 ROI 设计动机 |
| Stage 4 两折 | 预注册选择依据 | 决定六折扩展模式 |
| BC-DPG v3 | 六折分组内部验证 | 当前虚警校准主结论 |
| 最终联合审计 | 六折、1,148 行精确对齐 | BC-DPG 与 ROI 的固定阈值互补性 |

## 7. 不能从当前结果推出的内容

- 不能声称已经完成空飘球有载/无载或载荷类型识别；
- 不能声称已经通过跨场地、跨天气或跨日期独立盲测；
- 不能把完整扫描上下文 BC-DPG 描述为严格实时因果模型；
- 不能把 AND、OR 或串联逻辑描述为已训练、已选择或已部署的联合模型；
- 不能用两折诊断结果替代六折主证据。
