# H/V 双极化雷达检测项目分享包

## 一句话介绍

本项目利用 H/V 双极化复数 IQ 雷达数据，研究低慢小目标的检测、距离—速度定位与背景虚警抑制。当前已经形成可复现的 UAV 检测定位前端和六折内部验证证据；空飘球有载/无载、载荷类型及运动状态识别属于后续目标，尚未由当前数据证明。

## 当前最重要的结论

| 方法 | 六折虚警数 | 正确检测 | 当前定位 |
|---|---:|---:|---|
| BC-DPG-FCN v3 | 56 | 289/318 | 当前最强检测器 |
| Power2 baseline | 300 | 268/318 | ROI 候选基线 |
| ROI power control | 237 | 268/318 | ROI 机制对照 |
| ROI RI4 | 196 | 268/318 | 独立极化抑制研究 |

BC-DPG-FCN v3 与 ROI RI4 的 OR/union 可得到 294/318 个正确目标，但虚警升至 216；AND/intersection 可把虚警降至 36，但正确检测降至 263。两者只用于描述互补性，没有作为部署规则，也没有依据测试集重新选阈值。

## 包内内容

- `docs/`：项目介绍、开发历史、结果说明、分享提纲与后续计划。
- `assets/figures/`：可直接用于介绍的精选 PNG 和论文 PDF 图件。
- `assets/tables/`：主要冻结结果 CSV。
- `evidence/`：四个阶段的冻结结论或正式报告。
- `MANIFEST.json`：版本、范围、源文件及 SHA256 哈希。
- `SHA256SUMS.txt`：包内文件完整性校验值。

## 分享边界

本包不包含原始 MAT/IQ 数据、标签明细、逐样本预测、checkpoint、训练日志、开发聊天记录、个人路径或访问凭据。包内数字属于当前数据上的内部六折或明确标注的两折诊断证据，不代表跨场地盲测、严格实时部署或空飘球载荷分类性能。
