# 项目历史重建与认知修订

版本：2026-08-01  
用途：把本地历史聊天导出中的研究决策、数据认知和模型阶段整理成一份可引用的历史记录。本文不是原始聊天记录，也不替代当前冻结证据。

## 1. 阅读范围与方法

本次审计阅读了本地“有用？”目录中的 14 份 Markdown 导出，并对照了当前仓库的
`docs/share/`、`docs/CURRENT_STATUS.md`、模型选择台账、数据卡和最新 V2 结果。14 份导出
均为不同 SHA256 的文件，未发现可以确认的完全重复文件。导出文件名中的数字是对话导出
顺序标识，不应当当作雷达采集时间或实验时间戳。

原始聊天适合回答“当时为什么这样做”，不适合直接证明“现在仍然成立”。因此本文对每个
重要历史结论都做了三类标记：

- **保留**：与当前冻结证据一致，可以继续引用；
- **修订**：历史判断有价值，但数字、名称或适用范围已经改变；
- **降级**：曾经用于开发决策，后来发现有泄漏、条件不足或测试后选择，不能当作盲测结论。

## 2. 项目目标如何逐步收敛

最初的任务同时包含论文复现和大创长期目标。历史记录中一度把两者混在同一条模型线
上，后来才明确拆成两条成熟度不同的工作流：

1. **当前可验证主线**：使用学长提供的 H/V 双极化 UAV 与背景数据，完成检测、距离—速度
   定位和背景虚警抑制；
2. **长期大创主线**：在获得真实空飘球及载荷数据后，逐级研究目标类别、有载/无载、
   载荷类型和运动状态，并融合时域、极化、微多普勒、轨迹及环境信息。

因此，当前项目的准确名称应理解为“面向未来空飘球辨识的 H/V 双极化 UAV 检测定位与
虚警抑制前端研究”。现有 UAV 数据不能直接证明空飘球载荷分类，也不能证明 UAV 到
空飘球的跨平台泛化。

历史记录中还出现过一个“全球风险感知模型”支线。它属于独立的暑期探索，不是雷达项目
的算法阶段，不应写入雷达论文、分享包或模型排行榜。

## 4. 数据认知的关键修订

### 4.1 从“318 个样本”到“多层独立单位”

早期记录把 318 个 UAV 文件当作主要样本单位，并用 228/45/45 或类似随机划分推进
训练。后续审计发现同一扫描、波束或时间片可能被拆入不同集合，因而建立了按 source/scan
分组的 V3/V4 清单。当前冻结评价使用 1,148 个样本、六个外层折和扫描组，而不是把
文件数量直接当作独立飞行事件数量。

### 4.2 类别与日期完全耦合

当前冻结审计中的目标扫描组来自 `20260202`，背景扫描组来自 `20260204`。因此，任何
目标/背景 AUC、单特征 separability 或虚警改善都可能包含日期、场景、设备状态和采集流程
差异。分组隔离解决了相邻文件泄漏，但没有解决跨日期混杂；必须用同日目标/背景和新日期
锁定盲测补足这一点。

### 4.3 物理参数不能由文件名推断

历史 MATLAB 代码提供了 9.3 GHz、约 1450 Hz PRF、30 m/gate、128 脉冲等重建参数，且
早期验证显示标签可以落到 RD 图峰值附近。这足以支持当前工程输入接口，但还不足以证明
连续慢时间关系、真实硬件时间戳、H/V 相干、绝对幅相标定或物理微多普勒频率。当前资料
没有经过验证的逐样本采集顺序，MAT 头时间和文件 mtime 不能替代采集时间。

## 5. 模型线如何从“加网络”转向“先解释虚警”

历史中曾有“先做 Transformer/注意力/更复杂多域融合”的倾向，后来被数据审计和失败
实验纠正。模型线的实际演化是：

```text
H/V 正样本定位
  -> H、V、HV 功率检测基线
  -> DPG-FCN 门控定位
  -> 样本独立 BC 与完整扫描 BC-DPG v3
  -> 显式极化全图表征（未超过 Power2）
  -> Power2 候选锚定的 ROI 极化精修
  -> 零多普勒固定抑制与目标保护残差
  -> 等待真实顺序、标定和外部盲测
```

当前最有解释力的问题不是“哪个网络更大”，而是：

- 虚警是否由零多普勒附近的背景机制集中造成；
- 扫描上下文收益是否依赖未来信息；
- 极化增益是否在跨采集组仍稳定；
- 抑制模块能否在不损失目标和定位的情况下工作。

## 7. 对外材料应采用的历史叙事

推荐用下面的因果链，而不是按聊天逐条罗列：

1. 先完成 IQ、RD 轴和标签接口，证明输入可读、坐标可核对；
2. 通过 H/V/HV 基线发现双通道存在互补，但简单融合也会带来背景误警；
3. 通过分组审计发现旧随机划分不足，转向 source/scan 隔离和六折评价；
4. 通过 BC-DPG 识别背景分布迁移，把研究重点从“定位误差”转向“虚警与目标保护”；
5. 通过 Stage 3/4 发现全图显式极化不稳定，改为候选 ROI 局部编码；
6. 通过因果上下文和日期混杂审计，明确完整扫描结果是离线上限而非在线部署；
7. 通过 Tian 复现失败和零多普勒机制实验，保留可解释的失败证据，停止无约束扫网络；
8. 把下一阶段资源投向真实时间顺序、H/V 标定、连续慢时间和同条件空飘球数据。

## 8. 当前历史结论与下一步的关系

历史记录支持的下一步不是恢复所有已删除的训练输出，也不是把每一轮实验都重新跑一遍。
应当：

- 把已有冻结结果和失败诊断作为版本化证据；
- 对新实验记录数据清单、分组协议、配置、代码提交、checkpoint 哈希、训练日志和结果摘要；
- 只在验证集选择结构、损失、阈值和后处理；
- 外层测试只评价一次，且单独报告 pooled、macro、最差折和扫描组不确定性；
- 新数据先通过 capture、causal、locked-evaluation 三档合同预检；
- 真实空飘球数据到位后，再从检测前端转入有载/无载和运动状态分类。
