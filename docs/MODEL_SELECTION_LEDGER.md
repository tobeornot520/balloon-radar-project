## 1. 必须使用的证据标签

- `historical development baseline`：旧固定划分或早期实验；
- `development-fold screening`：使用 Fold 1/4 等困难折做结构或模式筛选；
- `internal grouped cross-validation`：当前六折开发估计；
- `post-test diagnostic`：不用于选择的测试后审计；
- `locked external blind test`：当前尚不存在。

“没有重新调整测试阈值”只说明阈值没有在测试集上重选，不等于网络结构、损失、表征或结果叙事完全没有受测试反馈影响。

## 2. 当前结论的严格定位

完整扫描上下文 BC-DPG-FCN v3 使用同一扫描的整体统计量，可能包含当前样本之后的信息。它应表述为：

> 当前扫描组隔离六折内部验证中表现最好的离线扫描感知方案，代表完整扫描上下文条件下的性能上限。

Sample-independent BC 不使用扫描上下文，是当前更接近在线部署条件的对照；冻结 past-only 敏感性审计已经完成，但严格实时方案仍需按真实时间顺序重新训练，并在验证集选择历史窗口。

现有 past-only 审计只替换冻结完整模型的推理上下文，没有使用 past-only 重新训练。顺序由 beam、azimuth 和 sample ID 推断，也未使用验证集选择窗口。因此它只证明当前 checkpoint 对历史上下文存在可测敏感性，不能替代新的因果训练、验证选择和锁定测试。

## 3. 获得无偏最终性能所需步骤

1. 冻结数据处理、网络结构、损失、超参数、阈值和后处理规则。
2. 使用未参与任何结构和叙事选择的新日期/新场地扫描作为盲测。
3. 或采用嵌套扫描组交叉验证，使外层 fold 不参与内层选择。
4. 盲测前登记主指标、最差条件、置信区间和失败判据。
5. 只进行一次最终评价，并保留完整选择台账和提交哈希。
