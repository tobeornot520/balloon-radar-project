## 5. 逐样本机制结论

- Fold 1中Power2检测53/53个目标，仅1个因定位失败而未联合命中；门控Polar6检测53/53，但14个定位失败。
- Fold 4中Power2检测52/52，11个定位失败；RI8-gated检测45/52，6个定位失败。
- 因此Polar6-gated的主要瓶颈不仅是阈值，还包括RD峰定位质量下降。
- RI4主要以降低目标分数和漏检为代价换取低虚警。
- Fold 1中其他三种表征没有救回任何Power2联合失败目标；Fold 4中每种表征均救回3个Power2失败目标，但同时造成更多退化。
- RI4与RI8-gated的虚警基本是Power2虚警的子集；Polar6-gated在Fold 4产生1个Power2没有产生的新虚警。

## 6. 决策

1. 不将Polar6-gated或RI8-gated直接替代Power2。
2. 暂不把四种表征全部扩展至六折。
3. Stage 3应冻结为“门控机制有效，但显式极化密集输入尚无稳定独立增益”的阶段性结论。
4. 下一步采用Power2作为主检测和定位通道，只在Power2候选峰局部ROI内提取极化特征，开展候选区域引导的极化精修。
5. 新阶段先在Fold 1与Fold 4比较：Power2原始基线、Power2+ROI功率控制、Power2+ROI RI4、Power2+ROI gated Polar6；保持样本独立，不混入扫描上下文。

## 7. 证据边界

当前只有两个困难折，且同一测试结果已用于开发判断。本结果适合方法诊断和下一阶段设计，不应写成跨环境独立泛化结论。
