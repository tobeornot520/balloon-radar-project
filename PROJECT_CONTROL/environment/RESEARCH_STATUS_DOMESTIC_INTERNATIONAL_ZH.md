# 雷达低空目标、气象场地环境与抗干扰研究现状及不足

版本：V1.0  
日期：2026-09-18  
用途：项目申报书、论文绪论、组内汇报和环境方向调研的共同底稿

## 1. 综述范围与证据边界

本文围绕本项目的实际问题组织国内外研究现状：

```text
雷达发现低空/慢速弱目标
  -> 极化、微多普勒和多域特征识别
  -> 天气与场地杂波条件下的虚警抑制
  -> 干扰、实时性和跨场地部署
```

“国内”和“国际”在本文中按研究来源划分，不是对一个国家全部文献的系统计量统计。当前内容基于项目已经登记的公开论文、国内学位论文、项目申报材料和环境/干扰文献包；尚未完成 CNKI、Web of Science、IEEE Xplore 等数据库的系统检索。因此，本文适合做**研究现状草稿和项目定位**，不能表述为穷尽式综述或文献计量结论。

本文还严格区分三个层次：

- **文献已经报告的结果**：只能在该论文的雷达体制、目标、数据和划分条件下成立；
- **对本项目的可迁移启发**：需要重新设计数据合同和实验验证；
- **本项目当前证据**：现有数据主要支持 H/V UAV 与背景的检测、定位和虚警抑制，不支持已经完成空飘球载荷识别、绝对极化解释或实时部署。

当前项目主线状态仍以 [TASK_BOARD.md](../TASK_BOARD.md) 为准，方向保持 `4/6 BLOCKED_EXTERNAL`。环境方向的具体设计见 [ENVIRONMENT_PROJECT_DESIGN_REPORT_ZH.md](ENVIRONMENT_PROJECT_DESIGN_REPORT_ZH.md)。

## 2. 领域问题的基本结构

空飘球及其载荷属于低空、低速、弱散射且受风场显著影响的目标。对雷达而言，难点不是单一的“分类器不够复杂”，而是四个问题同时存在：

1. **目标回波弱且接近近零多普勒**：容易与地面、建筑、树木和系统底噪混淆；
2. **球体、绳索和载荷形成耦合散射中心**：载荷差异可能小于姿态、距离和信噪比变化；
3. **风、降水、遮挡和场地背景会改变目标与背景**：目标类别、日期和场地很容易形成数据捷径；
4. **雷达数据合同和外场真值要求高**：没有连续时间、同步真值和配置记录，无法可靠研究微多普勒、风场辅助或实时因果处理。

因此，研究现状不能只按“传统方法/深度学习”划分，还需要按目标特征、环境背景、干扰来源和部署证据分层。

## 3. 国际研究现状

### 3.1 极化雷达用于相似低空目标分类

国际研究在鸟类、无人机等相似低空目标区分方面形成了较成熟的极化特征路线。Torvik、Olsen 和 Griffiths 的鸟类/UAV 研究表明，共极化、交叉极化、相关性和去极化相关参数能够补充单一功率或运动特征；这类工作说明极化信息可能反映目标结构和散射机制差异。

Sethuraman、Yarovoy 和 Fioranelli 的 UAV 载荷极化分类研究进一步将问题从“是什么目标”推进到“是否带载荷/载荷状态如何”。其方法使用多极化通道和统计特征，并比较单通道决策与特征集成，直接启发了本项目的“Power2 基线、显式相对极化特征和公平融合比较”设计。

**现状特点：**

- 极化特征已从简单通道功率比扩展到相关性、熵、散射统计和多通道联合；
- 研究对象主要是鸟、无人机和其他空中目标，直接面向空飘球载荷的公开研究仍少；
- 许多结果依赖已标定的全极化或明确的 H/V 通道，不能自动迁移到未确认物理含义的项目通道。

### 3.2 微多普勒与时频识别

鸟和无人机的微多普勒研究已经较系统。Rahman 和 Robertson 在 K/W 波段观测旋翼和翼拍动产生的周期脊线、谐波和谱展宽；相关研究通常使用连续慢时间数据和 STFT 等时频表示。Moore 等进一步使用三维部件、旋翼运动参数和实验测量构建可验证的无人机微多普勒仿真。

这类研究确立了一个重要链条：

```text
局部散射点运动
  -> 慢时间复回波相位变化
  -> 多普勒/时频结构
  -> 目标或状态判别
```

但空飘球与无人机不同：球体摆动、载荷悬挂、绳索运动和风场驱动往往是低频、非平稳、非刚体耦合运动。国际微多普勒成果可以提供分析工具和仿真思路，却不能直接提供空飘球载荷的特征字典。

### 3.3 小样本和统计检测

有限数据条件下的参数化检测综述和滑窗/CFAR 研究表明，在背景样本有限、杂波非均匀的场景中，简单统计模型仍然具有重要价值。参考窗、保护单元、局部背景估计和恒虚警设计可以作为深度模型之前的可解释基线。

雷达杂波分类研究开始使用隐变量、协方差模型和 EM 类方法，把不同距离单元分为统计上较同质的背景子集。协方差估计和随机过程研究则进一步描述重尾、相关和低秩结构，为合成压力测试和自适应检测提供理论基础。

**现状特点：**

- 研究已经从“全场统一阈值”发展到局部背景、异质杂波和协方差结构；
- 统计模型可解释、计算量低，适合做复杂模型的公平对照；
- 统计自洽不等于场地真实，合成杂波必须用独立纯背景验证。

### 3.4 气象、地物杂波与场地建模

云雷达和气象雷达研究通常利用反射率、谱宽、退偏比、扫描间相关性、高度、时间和季节等条件，采用概率分类、贝叶斯判断、空间连续性或双极化双扫描方法区分气象回波和地物杂波。

场地建模方向则有两类路线：

1. **经验路线**：用长期纯背景扫描统计固定峰、近零多普勒能量、占用率和分位数，形成场地杂波图；
2. **物理/地图路线**：将 DEM/DSM、地物类别、雷达位置、波束和采样几何连接起来，仿真可能的地杂波分布。

数字地表地图、城市道路几何和复杂地形研究说明，遮挡、建筑方向、树木和固定反射体会改变可见区域和检测概率。但这些研究一般需要明确的雷达几何、传播参数和场景地图；地图预测也不能替代现场背景观测。

### 3.5 射频干扰和系统抗干扰

国际 RFI 研究覆盖 SAR 射频干扰、汽车 FMCW 多雷达互扰和时频稀疏干扰。方法大致分为：

- 采集前的频谱、时隙和波形协调；
- 接收端的检测、陷波、零置和自适应抵消；
- 插值或自回归重建；
- 稀疏/低秩分解；
- CNN、全卷积网络和 Transformer 等学习型恢复。

这些研究的重要共识是：干扰抑制不能只用“输出图像更干净”评价，还要检查目标峰是否移动、检测率是否下降、定位是否受损以及本地计算是否可接受。

但是，现有抗干扰论文中相当一部分基于汽车 FMCW 或 SAR 数据，和当前项目是否为同一雷达体制尚未确认。仿真干扰如果没有真实干扰统计锚定，也只能是压力测试。

### 3.6 国际研究的总体趋势

国际研究大致呈现以下趋势：

1. 从单一幅度检测转向极化、时频、轨迹和上下文的多域表示；
2. 从均匀背景假设转向异质杂波分类和环境条件化检测；
3. 从单次识别转向场地地图、历史背景和连续轨迹建模；
4. 从离线去干扰图像质量转向下游目标保护和系统资源约束；
5. 从大模型性能展示转向仿真到真实、跨域和硬件部署问题。

但这些趋势并不意味着“复杂模型已经解决空飘球载荷识别”。直接、公开、可复核的空飘球多域数据仍然稀缺。

## 4. 国内研究现状

### 4.1 浮空目标极化散射、检测与识别

项目资料中最接近本方向的国内代表性工作是黄建开的博士论文《浮空目标雷达极化特性分析及应用研究》（国防科技大学，2025）。该研究形成了较完整的“散射机理—极化检测—目标识别—载荷辨识”链条：

- 对金属球、椭球和浮空目标开展极化散射区理论、数值仿真和暗室测量；
- 提出基于相干脉冲修正比和双极化通道相关性的浮空目标检测思路；
- 利用地杂波相关性处理雷达方位校准问题；
- 研究浮空目标与无人机的双极化微动和相位一致性差异；
- 进一步建立外挂载荷多点散射模型，并用时频/图像形态特征进行载荷辨识。

这项工作表明，国内已经不只是做一般低空目标检测，而是开始把浮空目标的散射机理、极化信息、地杂波抑制和载荷判别连接起来。它对本项目最直接的启发是：多域融合应有物理和实验依据，目标保护、杂波相关性以及载荷造成的多散射中心都值得纳入数据设计。

但该论文的实验设备、极化标定、目标构型、观测几何和数据划分属于其自身研究条件。论文中的检测率、识别率和阈值不能直接作为本项目结果；尤其不能用当前尚未完成绝对幅相标定的 H/V 数据复述其绝对极化结论。

### 4.2 风场反演、轨迹预测与载荷判断

王雪松等在《雷达风场反演下的空飘球轨迹预测与载荷判断》（《系统工程与电子技术》网络首发，2024）中，将雷达定位、VPP 风场反演、空飘球动力学模型和轨迹惯性度/质阻比结合，用于轨迹预测与载荷判断。该工作说明，风场不只是“天气标签”，还可能是解释空飘球运动、预测轨迹和辅助载荷判断的物理变量。

但该文的主要验证是仿真和模型误差分析，结论依赖风场反演、目标动力学和连续轨迹观测。它不能直接证明普通地面气象站的风速输入足以完成载荷识别，也不能替代本项目需要的同步雷达、视频、真值和连续时间记录。

### 4.3 国内低慢小目标和雷达智能识别基础

国内已有较多低慢小目标检测、HRRP/距离像、稀疏表示、深度网络、多域特征和小样本检测研究。项目申报材料将这些方向归纳为：弱特征增强、距离-多普勒/时频/极化特征提取、多域融合和复杂场景验证。

从技术基础看，国内研究具备以下优势：

- 雷达信号处理、极化散射、目标特性测量和外场验证基础较强；
- 面向低信噪比、复杂杂波和低慢小目标的工程问题较明确；
- 有将气象雷达、极化雷达和目标识别结合的研究积累；
- 近年来开始重视风场、轨迹和目标动力学信息。

### 4.4 国内杂波、射频干扰与气象雷达研究

国内相关参考文献中已经出现极化-多普勒气象雷达射频干扰滤波、基于高斯模型的自适应地物杂波滤波、极化雷达地杂波检测、谱退极化比杂波抑制、复杂地形气象雷达和杂波污染恢复等路线。

这些工作为项目提供了三类方法基础：

1. 利用双极化或谱特征区分地物/天气回波；
2. 用背景统计和相关性构造自适应杂波抑制；
3. 在信号域或频谱域恢复受到污染的观测。

但本项目当前并未对这些参考文献全部完成独立复现，且许多方法的雷达体制、气象产品和极化标定条件不同。正式论文应先核对原文和设备事实，再决定哪些方法可以进入实验。

### 4.5 国内研究的总体特点

国内研究更接近空飘球和气象雷达实际场景，尤其在极化散射、地杂波相关性、风场反演和外场验证方面具有较强针对性；但研究成果往往依赖特定雷达、特定场地、特定目标构型和课题组自建数据，公开数据、统一协议和跨场地复核相对不足。

## 6. 当前研究的主要不足

### 6.1 目标与载荷数据不足

直接面向空飘球“有载/无载/载荷类型”的雷达公开数据很少，且不同论文使用的球体、载荷、绳长、材质、观测距离和雷达体制差异很大。许多研究只能在仿真、暗室或少量外场样本上说明方法可行，尚不能形成跨对象实例、跨日期和跨场地的统一结论。

**对本项目的要求：** 建立同一对象无载/有载、稳定/摆动/旋转、多日期、多场地和纯背景对照；每个事件能追溯到原始文件、时间、配置和同步真值。

### 6.2 环境因素与目标类别容易混杂

不少研究能够说明算法在某个场景有效，但没有充分回答“性能来自目标特征，还是来自日期、场地、天气、增益或背景差异”。目标只在晴天采集、背景只在雨天采集时，即使分类结果很高，也不能说明模型学到了目标机制。

**对本项目的要求：** 同日期、同场地、同配置尽量同时采目标和纯背景；以 session、日期和场地作为外层分组；分别报告环境组和最差组结果。

### 6.3 快变气象研究与检测决策脱节

风、降水、能见度常被作为附带说明或类别标签，较少被严格连接到背景虚警、目标漏检和定位误差。风场辅助轨迹预测是一条独立研究路线，不能简单等同于“把天气数值拼到分类器输入”。

**对本项目的要求：** 先检验环境变量是否解释失败，再比较背景校准和轻量环境条件化；只有真实时间顺序和同步传感器满足时，才讨论 past-only 环境输入。

### 6.4 场地建模的物理精度与泛化之间存在矛盾

高精度 DEM/DSM、传播模型和电磁仿真能够描述具体站点，但数据和参数成本高，也可能让模型记住场地。纯数据背景图成本低，却可能在换场地、季节或施工后失效。

**对本项目的要求：** 先用多日期纯背景建立经验风险图，再用新日期和新场地检验；把场地先验明确定位为固定部署适配，不能默认是跨场地泛化。

### 6.5 极化结论依赖标定与通道事实

论文中的绝对极化参数、相位关系、相关系数和散射矩阵都依赖通道映射、同步、幅相标定和测量几何。仅凭文件中有 H/V 两列，不能确认具备可解释的双极化物理量。

**对本项目的要求：** 先完成 capability、同步、polarimetric calibration、dry run 和 pilot 五道门；在此之前，H/V 特征只能使用明确命名的相对量，并设置 `channel_validity` 屏蔽未验证通道。

### 6.6 抗干扰研究存在体制迁移风险

大量先进干扰抑制研究来自汽车 FMCW 或 SAR，而当前项目是否具有相同的 beat signal、调频结构、阵列通道和干扰参考尚未确认。直接移植网络可能产生“去掉了目标”的伪改善。

**对本项目的要求：** 先建立真实干扰和系统故障目录；从质量标记、拒收、插值和 AR 等简单方法开始；所有方法都要检查目标峰移动、Joint Pd、定位和延迟。

### 6.7 评价指标与部署证据不完整

只报准确率、AUC 或单次识别率，无法回答工程系统最关心的虚警预算、定位质量和连续运行。样本级随机拆分还会把同一扫描或同一 session 的相关样本泄漏到训练与测试。

**对本项目的要求：** 主指标采用 `Pfa`、`Score Pd`、`Joint Pd`、距离/速度/角度误差、worst group 和 P50/P95/P99 延迟；数据按 session/date/site 外层隔离，并最终预留一次 locked external blind test。

### 6.8 可复现性和数据共享不足

不少目标识别研究依赖不公开的雷达原始数据、设备参数和现场标签，外部研究者难以复核；即使公开了代码，也可能缺少时间同步、配置、校准和目标真值。

**对本项目的要求：** 将数据 manifest、配置、标定 ID、代码提交、模型哈希、阈值规则、日志和结果摘要绑定到 `experiment_id`，并把不可公开的原始数据替换为可审计的数据合同和汇总证据。

## 7. 面向本项目的研究切入点

综合国内外研究，项目不宜把创新点写成“首次使用深度学习识别空飘球”，更稳妥的切入点是：

> 面向固定或半固定雷达站点，在 H/V、距离-多普勒及后续时域/时频数据满足可验证采集合同的前提下，研究环境条件化的多域检测与虚警抑制；通过同条件目标/背景、跨日期/跨场地分组和因果回放，分析快变气象与慢变场地先验对 Pfa、Joint Pd、定位和实时性的影响。

可形成的研究层次如下：

### 第一层：环境作为评价条件

不改变模型，只记录风、雨、能见度、场地和系统状态，回答环境是否解释失败模式。

### 第二层：轻量背景校准

比较 Power2/RD、多域融合、CFAR、当前 session 背景统计和 past-only 校准，检查降低 Pfa 是否牺牲目标保护。

### 第三层：固定站点经验先验

用长期纯背景建立风险图，并检查同场地跨日期与跨场地性能；场地先验缺失时回退到基础模型。

### 第四层：真实干扰后的压力测试

在真实异常形态确认后，比较报警、拒收、插值、AR、稀疏/低秩和深度恢复；未锚定真实数据的合成干扰只用于软件压力测试。

## 8. 可用于论文绪论的总结段落

国内外研究已经在低空目标极化识别、微多普勒表征、气象雷达杂波抑制、场地背景建模和雷达干扰恢复等方面形成了较丰富的方法积累。国际研究在鸟类与无人机极化分类、微多普勒仿真、异质杂波统计建模和汽车/SAR 抗干扰方面较为系统；国内研究则在浮空目标极化散射、地杂波相关性检测、风场反演、轨迹预测和载荷辨识等方面具有较强的目标针对性。总体而言，现有研究仍存在直接面向空飘球载荷的公开多域数据不足、环境因素与目标类别容易混杂、固定站点先验跨场地泛化证据不足、极化和时域结论依赖设备标定、抗干扰方法存在体制迁移风险，以及评价指标和实时部署证据不完整等问题。因此，后续研究需要从可审计外场数据和同条件目标/背景对照出发，将多域融合、气象/场地分层、因果背景校准和部署资源评价统一起来，而不是仅通过增加网络复杂度追求单一识别率提升。
