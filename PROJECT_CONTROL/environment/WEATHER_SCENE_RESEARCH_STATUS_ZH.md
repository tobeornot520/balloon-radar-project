# 复杂气象与场景环境研究现状及不足

版本：V1.0  
日期：2026-09-18  
用途：环境方向调研、外场采集论证、论文绪论和导师汇报

## 1. 研究范围

本文只讨论“气象与场景环境”这一条线，不把一般目标分类、载荷识别网络和射频抗干扰作为主体。研究对象分成两类：

```text
快变气象环境
风、阵风、降水、能见度、温湿压、短时传播/背景变化
    -> 目标运动变化、天气回波、噪声底和虚警分布

慢变场景环境
地形、建筑、树木、地面、遮挡、固定反射体、雷达朝向
    -> 长期背景占用、可见区域、稳定杂波峰和场地先验
```

射频干扰、丢帧和时钟故障属于另一条“异常压力测试”线，本文只在需要区分环境来源时提及。

本文基于项目已登记的环境/干扰文献包、国内浮空目标论文和项目已有材料，属于代表性综述，不是 CNKI、Web of Science 或 IEEE Xplore 的穷尽式文献计量研究。文献来源及全文边界见 [环境与干扰文献登记](ENVIRONMENT_INTERFERENCE_LITERATURE_20260918.md)。

## 2. 国际研究现状

### 2.1 气象回波与非目标杂波区分

国际气象雷达研究已经形成较成熟的环境回波质量控制路线。云雷达研究通常联合反射率、谱宽、线性退偏比、观测高度、时刻和季节等变量，以概率分布、贝叶斯分类和空间连续性区分低层云、地物和其他非目标回波。双极化、双扫描地杂波研究则利用连续扫描之间的自相关/互相关和极化差异，判断信号是否具有固定地物的稳定性。

这类研究的共同变化是：

- 不再把“背景”看成一个固定噪声水平，而是区分多个统计状态；
- 不只使用单帧强度，还使用时间重复性、极化响应和空间结构；
- 输出不只是目标/非目标标签，还包括质量标记、背景类别或可信度。

对本项目的启发是，风、降水和场地变量首先应被当作**环境条件和质量控制变量**，用于解释 Pfa、漏检和定位误差；只有证实它们在同条件目标/背景中提供稳定增益后，才接入检测模型。

代表性材料包括 `CloudRadar_ClutterDiscrimination_2021`、`DualPolarization_DualScan_GroundClutter_2016` 和 `LearningStrategies_RadarClutterClassification_2020`，逐篇说明见 [环境与干扰知识储备](ENVIRONMENT_INTERFERENCE_KNOWLEDGE_BASE_ZH.md)。

### 2.2 风、降水与目标检测的关系

国际相关研究通常从三种机制处理天气影响：

1. **目标运动机制**：风改变漂浮目标速度、摆动、旋转和轨迹；
2. **背景运动机制**：树木、线缆、旗帜和其他柔性物体在风中产生运动回波；
3. **传播与观测机制**：降水、湿度和能见度变化可能影响衰减、散射、噪声底和真值设备可用性。

现有研究往往只深入其中一种机制。例如风场研究会把风速用于轨迹预测，气象雷达研究会把降水作为回波/杂波条件，场地研究会把树木和建筑作为背景结构。将三者与低空空飘球检测、背景虚警和定位误差放在同一数据合同中验证的公开研究较少。

### 2.3 固定站点杂波图与场景几何

国际场景建模主要有经验和物理两类。

**经验背景图。** 通过多次纯背景扫描统计每个距离、方位或距离-速度单元的均值、分位数、占用率、峰稳定性和时间变化，形成站点杂波图。它计算简单，适合固定部署，但容易记住场地并在换场地后失效。

**地图/物理模型。** 将 DEM/DSM、建筑和地表类型、雷达位置、天线方向图、波束宽度、俯仰角和采样几何连接起来，预测地物遮挡和强反射区域。数字地表地图研究还特别关注地图分辨率、方位采样间隔和建模功率误差之间的关系。

城市街道几何研究进一步说明，道路/建筑方向、遮挡、反射体分布、波束和噪声水平都会改变检测概率。因此 `site_id` 不应只是一个名称，还需要拆成朝向、遮挡扇区、固定反射体、背景运动和可见区域等变量。

代表性材料包括 `DigitalEarthSurfaceMaps_RadarGroundClutter_2022` 和 `UrbanStreetGeometry_RadarDetectionProbability_2023`。它们支持场景变量分解，但不提供当前合作场地的真实地图或回波真值。

### 2.4 非均匀背景的统计建模

滑窗检测和 CFAR 研究为复杂环境提供了基础参照：用参考单元估计局部背景，用保护单元避免目标污染，并按统计假设控制虚警。进一步的杂波分类、协方差估计和随机过程研究则处理非均匀、相关、重尾和低秩背景。

这些方法的共同价值是建立一个由简到繁的比较阶梯：

```text
全局阈值
  -> 局部背景/CFAR
  -> 环境状态分类
  -> 历史背景图与协方差
  -> 环境条件化学习模型
```

对本项目而言，不能跳过 CFAR、背景占用率和分位数等简单基线，否则无法判断深度环境模型是否只是学习了局部归一化。

### 2.5 国际研究的总体特点

国际研究在气象回波质量控制、非均匀杂波统计、地形/地表地图、城市几何和跨条件检测方面方法较多，但有三个明显限制：

- 研究对象常为气象回波、汽车、鸟或无人机，直接针对空飘球的证据有限；
- 物理地图研究通常需要精确雷达和地理参数，未必适合设备事实尚未确认的小型外场项目；
- 环境变量常用于分类或仿真，较少在同条件目标/背景和锁定外层下验证对 `Joint Pd`、定位和实时性的影响。

## 3. 国内研究现状

### 3.1 极化气象雷达与地物杂波

国内研究已经形成极化气象雷达地物杂波检测、相关性分析、谱域恢复和杂波抑制等方向。项目收集的国内文献线索包括：基于极化-多普勒信息的射频干扰滤波、基于高斯模型的自适应地物杂波滤波、极化雷达地杂波统计检测，以及谱退极化比杂波抑制等。

这些研究的共同思路是利用极化通道差异、扫描间相关性、信号统计或频谱变化，把固定地物/异常回波与期望气象回波区分开。它们为本项目提供了背景质量控制和相对通道特征的参考，但由于设备、极化产品和气象雷达扫描方式不同，不能直接转化为当前 H/V 输入的物理结论。

### 3.2 浮空目标与风场环境

王雪松等的《雷达风场反演下的空飘球轨迹预测与载荷判断》代表了国内将雷达目标观测、风场反演和空飘球动力学结合的路线。该工作通过局部风场、目标动力学和轨迹偏差推断空飘球的运动与载荷状态，说明风场可以是目标运动的物理解释变量，而不仅是“晴天/阴天”标签。

但该研究主要依赖风场反演、轨迹连续性和模型/仿真验证。要把它用于本项目，至少还需要：

- 可靠的连续雷达轨迹和真实时间顺序；
- 目标位置、速度和状态的同步真值；
- 风场测量或反演的空间范围与目标高度匹配；
- 同日期、同场地的背景对照。

普通地面风速仪的一个瞬时读数不能替代这些条件。

### 3.3 浮空目标场景与固定背景

国内浮空目标研究开始关注气象雷达复用、地杂波相关性、连续扫描方位校准和固定场地背景。黄建开《浮空目标雷达极化特性分析及应用研究》中的相关工作将浮空目标检测和地杂波相关性联系起来，并将连续扫描校准作为提高点迹稳定性的手段。

这说明国内研究已经认识到：目标特征之外，雷达朝向误差、地物背景和扫描稳定性也会直接影响浮空目标检测。但目前公开材料更多聚焦于特定雷达、特定实验场地和特定目标，关于跨日期、跨场地和环境条件变化的统一评估仍有限。

### 3.4 国内场景建模和工程应用特点

国内工程研究重视气象雷达、低空安防和固定站点应用，常将场地杂波、雷达校准、风场和目标轨迹结合起来。其优势是问题来源明确、实验与装备联系紧密；不足是原始数据、设备参数、标定条件和外场标签往往不公开，外部研究者难以复核。

相较于完整的 DEM/遥感反演，当前项目更适合先建立“雷达坐标系下的经验背景档案”：长期纯背景、雷达朝向、遮挡、固定反射体、背景占用率和峰稳定性。只有当设备几何、地理数据和外场重复性都满足后，再考虑地图辅助物理仿真。

## 4. 国内外研究对比

| 方面 | 国际研究现状 | 国内研究现状 | 当前共同不足 |
|---|---|---|---|
| 气象回波 | 云/降水/地物区分、双极化质量控制和概率分类较系统 | 极化气象雷达、杂波滤波和工程校准有积累 | 与空飘球目标检测的同条件证据不足 |
| 风场作用 | 常用于天气观测、目标运动或轨迹预测 | 已出现雷达风场反演与空飘球轨迹/载荷判断 | 风场空间分辨率、目标高度和同步真值难匹配 |
| 场地杂波 | 经验杂波图、DEM/DSM、城市几何和传播模型较丰富 | 固定站点背景、地杂波相关性和雷达校准较重视 | 地图模型与现场实测的联合验证不足 |
| 背景统计 | CFAR、异质杂波分类、协方差和随机过程较成熟 | 自适应地物滤波和极化统计方法较多 | 小样本、相关扫描和最差组不确定性常被低估 |
| 数据集 | 部分气象/汽车/无人机数据可用 | 空飘球环境数据主要依赖自采 | 缺少同日期/场地/配置的目标-背景成对数据 |
| 部署评价 | 开始关注跨域、仿真到真实和计算资源 | 强调外场可用性和装备约束 | 严格 causal、locked test 和跨场地公开证据不足 |

## 5. 研究不足

### 5.1 缺少“目标—背景—气象—场地”同步数据

现有研究常分别研究天气回波、场地杂波或目标识别，真正同时记录目标事件、纯背景、风/雨、场地结构、雷达配置和同步真值的数据很少。这导致环境变量很容易和目标类别、日期或场地绑定，无法回答“天气是否造成性能变化”。

### 5.2 风场研究与检测前端脱节

风场反演和轨迹预测往往以连续轨迹和动力学参数为中心，而目标检测网络关注单帧或短窗口分数。两者之间缺少可验证接口：风场输入的空间位置、时间延迟、目标高度和不确定性没有统一记录。

### 5.3 降水和传播影响缺少面向低空目标的定量评估

降水可能带来天气回波、噪声底变化、传播衰减和真值设备失效，但不同雷达频段、距离和降雨强度下的影响不同。现有气象雷达研究不能直接给出当前设备对空飘球目标的检测损失，需要现场配对和设备级测量。

### 5.4 场地地图存在“记忆场地”风险

固定背景图在原站点可能有效，但模型可能只是记住某个方位/距离位置。施工、季节、树木生长、车辆停放和雷达重新架设都会改变先验。跨场地和新日期评价仍是场地建模的关键短板。

### 5.5 物理地图与经验地图之间缺少校准闭环

DEM/DSM 可以描述地形和建筑，但不能直接给出雷达回波强度；经验背景图能反映实测回波，却不一定能解释新场地。现有工作往往分别开展，缺少“地图先验—实测纯背景—异常更新—跨日期验证”的完整闭环。

### 5.6 环境变量缺乏因果和在线约束

不少工作使用事后天气标签或完整扫描统计，离线结果不能直接说明在线系统可用。若没有逐样本 UTC 时间、硬件序号、丢帧和重启记录，past-only 历史模型和实时环境适配都无法严格验证。

### 5.7 评价指标不够贴合雷达任务

环境模型不能只报告气象类别准确率或 AUC。工程上需要知道：背景 `Pfa` 是否下降、`Score Pd` 和 `Joint Pd` 是否受保护、定位是否改变、最差环境组是否改善、延迟和内存是否可接受。

### 5.8 复杂模型的收益与代价缺少同时评价

气象传感器、场地地图、额外校准和大型网络都会增加部署成本。若仅有小幅 Pfa 改善，却需要高频三维风场、遥感地图或 Transformer，未必适合作为固定站点系统。

## 6. 对本项目的研究定位

当前不宜把研究目标写成“建立通用复杂气象模型”，而应收敛为：

> 面向固定或半固定雷达站点，研究快变气象条件和慢变场景先验对低空目标检测可靠性的影响，并在同条件目标/背景和跨日期/场地评价下，验证轻量、因果可用的背景校准是否能够降低最差环境组虚警，同时保护检测、定位和本地实时性。

建议采用以下技术路线：

```text
E0 设备能力、时间同步和气象/场地字段确认
  -> E1 同日期同场地目标/背景 Pilot
  -> E2 按风、雨、能见度、场地分层的失败分析
  -> E3 CFAR/背景统计/past-only 轻量校准
  -> E4 多日期经验场地背景图
  -> E5 新场地与新天气 locked evaluation
```

第一阶段不要求完成完整 DEM 反演、三维风场或天气分类网络；这些属于条件满足后的扩展方向。

## 7. 可形成的项目贡献

如果后续数据和设备事实能够通过，项目的环境方向可能形成以下贡献之一：

1. **环境分层证据。** 说明哪些天气/场地条件真正改变 Pfa、Joint Pd 或定位误差；
2. **因果背景校准。** 在只使用当前与过去信息的条件下，降低最差环境组虚警并保护目标；
3. **固定站点经验先验。** 用多日期纯背景构建风险图，并明确同场地收益和跨场地降级边界；
4. **环境—多域融合接口。** 证明环境变量加入检测器的增益足以抵消传感器、标注和计算代价；
5. **可复现实验合同。** 提供目标/背景、气象、场地、时间、配置和锁定评价的完整数据规范。

这些贡献都依赖新外场数据，不能由现有 UAV/背景内部六折结果直接推出。

## 8. 后续调研任务

### 8.1 先做范围界定

形成一页《复杂气象与场景环境调研范围界定》：

| 纳入 | 暂不纳入 |
|---|---|
| 风、阵风、降水、能见度的检测影响 | 完整大气动力学反演 |
| 固定站点经验杂波图 | 高精度全波电磁场景仿真 |
| DEM/DSM/遥感作为场地先验 | 把地图当作回波真值 |
| 同条件目标/背景环境分层 | 用日期或天气标签替代真值 |
| 轻量 CFAR、背景校准和 past-only 回放 | 在无时间合同前宣称实时 |

### 8.2 文献输出

每条调研线提交：3–5 条关键发现、对本项目的启示、不可迁移的前提、待向导师/设备方确认的问题和下一步实验。

### 8.3 设备与外场确认

至少确认：

- 雷达原始数据层级、H/V 含义、PRF、距离/速度映射和配置记录；
- 是否有逐帧 UTC/硬件时间、丢帧和重启日志；
- 气象传感器的类型、位置、采样率和同步方式；
- 场地是否有 DEM/DSM、平面图、建筑/树木/遮挡资料；
- 哪些天气条件可以安全采集，哪些条件必须终止；
- 是否可以取得同日期、同场地、同配置的纯背景对照。

## 9. 适合论文绪论的总结

现有国内外研究已经在气象雷达回波质量控制、双极化地物杂波识别、非均匀背景统计建模、固定站点杂波图、DEM/DSM 辅助场景建模和风场驱动的浮空目标轨迹预测等方面形成了方法基础。国际研究在环境回波分类、局部统计检测和场景几何建模方面较为系统，国内研究则在极化气象雷达、浮空目标地杂波抑制、风场反演和固定站点工程应用方面具有较强针对性。然而，现有研究仍缺少面向空飘球检测的同步“目标—背景—气象—场地”数据，快变气象与慢变场景对虚警、定位和目标保护的联合影响尚未充分量化，地图先验的跨日期/跨场地泛化和在线因果可用性也缺少严格验证。因此，本项目应从环境记录、同条件对照和经验背景图开始，逐步评价轻量因果校准和场地先验，而不应在设备事实和数据合同尚未确认时直接承诺完整风场反演、全波场景建模或通用复杂气象识别。
