# Tian 2024 复现结果整合包

这是一个轻量的结果阅读和交流包，不是完整重训练包。组员同步包只携带聚合摘要、配置和结果图；逐样本预测、训练历史和阈值曲线留在负责人本地受控目录，需要时单独申请。

## 先看什么

1. `ACTUAL_RESULTS_FOR_SENIOR_ZH.md`：四张实际结果图、真实样本示例和解释，优先给学长看。
2. `RESULT_SUMMARY_ZH.md`：所有主要实验结果和结论边界。
3. `FAILURE_REASON_SIMPLE_ZH.md`：用简单语言解释为什么没有复现成功。
4. `figures/`：由真实预测和审计数据生成的结果图。
5. `evidence/`：关键聚合 JSON、CSV，可用于核对总体结论；完整逐样本表不进入普通成员同步包。
6. `configs/`：对应实验的配置和预登记文件。

## 包含内容

- 原始 H-only 六折历史汇总；
- Fold 1 扩展 GT、point-GT 和两项负监督诊断证据；
- 上述四次 Fold 1 实验的聚合 summary；训练历史、验证预测和阈值曲线只保留在负责人本地；
- 原 Tian 固定模板审计；
- 六通道 adapter 验证和冻结背景评价；
- 四张结果图、关键配置文件、聚合结果和数据可辨识性摘要。

## 不包含内容

- 原始雷达数据；
- 作者原始代码；
- 可证明与论文作者一致的 checkpoint；
- 完整训练环境和作者侧输入-标签-输出对齐样例。

因此，这个包支持结果复核和向学长说明失败原因，不支持单独重新训练出论文结果。

## 原始来源

所有证据均从仓库中的 `results/` 和 `configs/` 复制而来。原始证据目录和专题主文档仍保留，
本包中的文件是集中阅读用副本。

负责人本地的 `evidence/*_tables/` 保存之前各次实验的原始表格。其中
`corrected_expanded_gt_fold01_tables/` 是修正后扩展 GT，另外三个目录依次对应 point-GT、
随机负样本和同距离列密集负样本。六折第一轮只保留聚合表和逐折表，因为其旧指标实现后来
被确认有误，不应作为正式论文指标引用。
