# 论文区

- `references/`：本地参考论文、学位论文和教材。全文默认不进 Git 或分享包；题录、来源、许可和哈希登记在 `docs/RECOMMENDED_PAPERS_20260805.md`。
- `drafts/`：论文草稿和待审版本。
- `figures/`、`tables/`：论文图表的源文件和导出文件。
- `archive/`：不再作为当前论据的旧稿和历史交付材料。
- `TIAN_2024_reproduction_topic/`：Tian 2024 专题索引与独有复现结果；正式文档链接回 `docs/`，论文链接回 `references/`，不保留副本。

论文叙事必须以 `docs/CURRENT_STATUS.md`、`PROJECT_CONTROL/TASK_BOARD.md` 和冻结结果为准。当前 UAV 检测证据不能扩写为空飘球载荷识别结论。
