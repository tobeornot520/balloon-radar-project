# 显式极化表征基准 Stage 2

本补丁在当前冻结的 BC-DPG-FCN v3 之外建立一条独立实验线，不修改或覆盖已有 v3 结果。

## 目标

在同一个固定参数量、固定 8 通道输入的 FCN 下比较：

- Power2：H/V 功率 RD；
- RI4：H/V 复数 RD 的实部和虚部；
- Polar6：H/V 功率 + 相对 ZDR 类特征 + 局部 rho_HV + 相对相位正余弦；
- RI8：RI4 + 4 个显式极化特征。

不足 8 个通道的模式用零通道补齐，因此四种模式网络结构和参数量完全一致。推理时只读取当前样本，不使用同扫描组其他样本。

## 科学边界

这一步是“输入表征比较”，不是最终多分支融合模型。未完成绝对 H/V 幅相标定，因此只能报告相对 ZDR 类特征和相对相位，不能称为绝对 ZDR 或 PhiDP。

## 建议流程

1. 安装补丁；
2. 运行管线单元测试；
3. 在 Fold 1、Fold 4 做四模式 smoke；
4. 验收后再决定是否跑完整六折正式实验；
5. 只有显式极化模式相对 Power2 显示稳定收益时，才进入显式极化分支设计。
